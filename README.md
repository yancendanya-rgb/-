# Затишна кава — лабораторна робота № 3

Адаптивний багатосторінковий сайт кав'ярні (HTML5 + CSS3), зверстаний за прототипом і дизайн-системою з практичної роботи № 2.

## Як запустити
Відкрийте `index.html` у браузері (окремий сервер не потрібен).

## Структура
- `index.html`, `menu.html`, `order.html`, `booking.html`, `contacts.html` — сторінки
- `css/fonts.css` — підключення шрифтів
- `css/tokens.css` — змінні дизайн-системи (кольори, шрифти, відступи)
- `css/base.css` — скидання, типографіка, контейнери, утиліти
- `css/components.css` — компоненти (кнопки, картки, навбар, форми тощо)
- `css/pages.css` — макети сторінок (Flexbox / Grid) і медіазапити
- `js/main.js` — допоміжна інтерактивність (меню, фільтр, лічильники)
- `images/` — SVG-ілюстрації (замінники фото; можна замінити власними)
- `fonts/` — Playfair Display, Inter, JetBrains Mono (локально, формат woff2)
- `screenshots/` — скриншоти сторінок: desktop 1440 px, tablet 768 px, mobile 375 px
